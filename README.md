# Feliz cumpleaños, Amanda Ximena 🌼

Proyecto estático HTML/CSS/JavaScript, personalizado para Amanda Ximena Roldán Medina.

## Publicar con GitHub y Render
1. Descomprime este ZIP.
2. Sube `index.html`, `render.yaml` y la carpeta `assets` a la raíz de un repositorio GitHub.
3. En Render, elige **New + → Static Site** y conecta el repositorio.
4. Deja vacío **Build Command** y coloca `.` en **Publish Directory**.
5. Pulsa **Create Static Site**.

No requiere Python, base de datos ni dependencias.

## Música
La página tiene un reproductor preparado para un archivo `assets/himno.mp3`.
Agrega ahí un himno instrumental que tengas derecho a usar. El ZIP no incluye música para evitar distribuir grabaciones protegidas por derechos de autor.

## Personalizar
Edita `index.html` para cambiar cualquier mensaje, versículo o firma.
